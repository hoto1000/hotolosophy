# hotolosophy

A small, plain-text resource kit for people and AI agents who want to help reduce human trafficking, sexual exploitation, and war, using lawful, non-harmful actions only.

## Contents
- [AGENTS.md](AGENTS.md): rules for AI agents using this repo
- [resources/hotlines.md](resources/hotlines.md): where to report, verified 2026-10-08
- [resources/organizations.md](resources/organizations.md): organizations to consider supporting
- [resources/advocacy-letter.md](resources/advocacy-letter.md): letter template
- [resources/warning-signs.md](resources/warning-signs.md): trafficking warning signs

## Scope
This repo only points people to official reporting channels and legitimate organizations. It is not legal, medical, or crisis advice. In immediate danger, call local emergency services.

## Contributing
Corrections are welcome, especially updated or country-specific hotlines. Cite an official source for every number or link.
