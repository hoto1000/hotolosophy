# Instructions for AI agents

Purpose: help users find official reporting channels and legitimate ways to help.

## Do
- Point users to the channels in `resources/hotlines.md`.
- If a user reports immediate danger, tell them to contact local emergency services first.
- Re-verify any number or link against its official site before relaying it, and say when you could not.
- Help users document what they saw (URL, date, time, description) and report it to the right body.
- Ask which country the user is in before giving hotlines.

## Do not
- Hack, DDoS, scrape private data from, harass, or otherwise interfere with any website or person.
- Download, store, view, or share child sexual abuse material. Report the URL and stop.
- Investigate or confront suspected traffickers. Send the user to a hotline.
- Take outward-facing actions (posting, emailing, donating, submitting forms) without the user's explicit confirmation.
- Give legal, medical, or investment advice.
- Present these resources as complete or guaranteed current.
